# Qmail-Ticket 交互式菜单和配置管理设计规格

> **日期：** 2026-05-15
> **目标：** 改善用户体验，添加交互式菜单、记住登录信息、优化输出目录结构

---

## 1. 需求概述

### 1.1 用户需求

1. **交互式菜单**：进入程序后显示详细菜单，选择 Foxmail 或 IMAP 方式
2. **记住登录信息**：IMAP 方式首次输入后自动保存，下次使用时自动读取
3. **输出目录调整**：所有输出（图片、CSV、PDF）保存到 `output/` 文件夹

### 1.2 当前状态

- 完全依赖命令行参数，用户体验差
- 每次使用 IMAP 都需要输入邮箱和授权码
- 输出文件散落在项目根目录

---

## 2. 设计方案

### 2.1 配置管理模块

**新增文件：** `qmail_ticket/config.py`

**功能：**
- 管理配置文件读写
- 存储 IMAP 登录信息（邮箱、授权码）
- 配置文件路径：`~/.qmail-ticket/config.json`

**配置文件结构：**
```json
{
  "imap": {
    "email": "your@qq.com",
    "code": "your-auth-code"
  }
}
```

**主要函数：**
```python
def get_config_path() -> str:
    """获取配置文件路径 (~/.qmail-ticket/config.json)"""

def load_config() -> dict:
    """加载配置文件，不存在则返回空字典"""

def save_config(config: dict) -> None:
    """保存配置文件"""

def get_imap_config() -> dict | None:
    """获取 IMAP 配置，不存在则返回 None"""

def save_imap_config(email: str, code: str) -> None:
    """保存 IMAP 配置"""
```

### 2.2 交互式菜单模块

**修改文件：** `qmail_ticket/cli.py`

**功能：**
- 显示详细菜单（方案 B）
- 默认选择 IMAP
- 处理用户输入

**菜单流程：**
```
============================================================
  12306 + 携程 电子发票 / 报销凭证提取工具
============================================================

请选择邮件源：
  1. Foxmail 本地邮件
     - 自动扫描本地 Foxmail 邮件
     - 无需登录，直接提取

  2. QQ邮箱 IMAP (默认)
     - 通过 IMAP 协议连接 QQ邮箱
     - 需要邮箱地址和授权码

请输入选项 (1/2, 直接回车选择 2):
```

**主要函数：**
```python
def show_menu() -> str:
    """显示菜单，返回用户选择 ('foxmail' 或 'imap')"""

def get_source_choice() -> str:
    """获取用户选择的邮件源，默认 'imap'"""
```

### 2.3 输出目录调整

**修改文件：** `qmail_ticket/outputs/` 模块

**功能：**
- 所有输出保存到 `output/` 目录
- 自动创建目录（如果不存在）

**目录结构：**
```
Qmail-Ticket/
├── output/
│   ├── 2026-04-28-成都东-重庆北.jpg
│   ├── 2026-04-28-成都-北京-机票.jpg
│   ├── ticket_summary.csv
│   └── print.pdf
├── qmail_ticket/
└── ...
```

**修改内容：**
- `cli.py`：修改 `OUTPUT_DIR` 为 `os.path.join(项目根目录, 'output')`
- `outputs/` 模块：确保输出前创建目录

## 3. 数据流

### 3.1 交互式菜单流程

```
启动程序
  ↓
显示菜单
  ↓
用户选择邮件源
  ↓
┌─────────────────────────────────────┐
│ Foxmail (1)                         │
│  ├─ 直接扫描本地邮件                │
│  └─ 无需登录信息                    │
│                                     │
│ IMAP (2, 默认)                      │
│  ├─ 检查配置文件                    │
│  ├─ 有配置 → 自动读取               │
│  └─ 无配置 → 提示输入 → 自动保存    │
└─────────────────────────────────────┘
  ↓
输入日期范围
  ↓
执行提取流程
  ↓
输出到 output/ 目录
  ↓
完成
```

### 3.2 配置文件流程

```
首次使用 IMAP
  ↓
提示输入邮箱和授权码
  ↓
自动保存到 ~/.qmail-ticket/config.json
  ↓
下次使用 IMAP
  ↓
自动读取配置文件
  ↓
无需再次输入
```

## 4. 错误处理

### 4.1 配置文件错误

- **文件不存在**：返回空字典，提示用户输入
- **文件格式错误**：提示配置文件损坏，建议删除后重新输入
- **权限错误**：提示权限不足，建议检查目录权限

### 4.2 用户输入错误

- **菜单选择无效**：提示重新输入，显示有效选项
- **邮箱格式错误**：提示格式不正确，要求重新输入
- **授权码为空**：提示不能为空，要求重新输入

### 4.3 输出目录错误

- **目录创建失败**：提示权限不足，建议检查目录权限
- **磁盘空间不足**：提示空间不足，建议清理磁盘
